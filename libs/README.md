# Библиотеки

Все библиотеки, с которыми собирается прошивка, лежат здесь в проверенных версиях, а
`build.sh` подключает только эту папку. Для сборки в Arduino IDE её содержимое копируется в
папку библиотек Arduino (`Документы/Arduino/libraries`).

| Библиотека | Версия | Назначение |
|---|---|---|
| FastLED | 3.2.9 | математика эффектов |
| NeoPixelBus (Makuna) | 2.8.4 | вывод на ленту через UART1; master не собирается под ядро 3.x |
| Settings (GyverLibs) | 1.4.3, с правками | страница настроек |
| GyverDB, GyverHTTP, StringUtils, GTL, BSON, Stamp, Table, StreamIO, FOR_MACRO (GyverLibs) | связанные версии | зависимости Settings. Settings 1.4.3 требует BSON 3.0.0, а тот — GTL 1.4.7, поэтому библиотеки берутся отсюда все вместе |
| WiFiConnector (GyverLibs) | | подключение к WiFi |
| GyverButton (GyverLibs) | | кнопка |
| arduinoWebSockets (Links2004) | с правками | обновление виджетов открытой страницы |
| async-mqtt-client, ESPAsyncTCP | | MQTT |
| Time (TimeLib) | | разбор времени для часов и будильников; синхронизацию по NTP и часовой пояс даёт клиент SNTP ядра |

## Правки

**Settings.**

- `core/profile.h` и вызовы замеров: библиотека сообщает прошивке длительность каждого этапа
  обработки запроса страницы, и долгие этапы попадают в Журнал (`UI_PROFILE_MS` в `Config.h`).
- `SettingsT.h`: обновление прошивки и загрузка файла со страницы принимаются, только если
  записаны целиком, данные ждутся до 5 с. Без правки оборванная загрузка устанавливалась, и
  лампа перезагружалась в нерабочую прошивку.
- `core/SettingsBase.h`: без пароля значение виджета записывается в базу настроек, только если
  виджет открыт гостю. Без правки запись шла до проверки пароля.
- `web/settings.h`, скрипт страницы: число в спиннере открывает окно ввода, а ключ входа
  работает сразу после установки пароля. Правки вносит `Settings/web_patch.py`, он же
  обновляет метку кэша в адресе скрипта. После обновления Settings его нужно запустить заново.

**GyverHTTP.** `#ifndef` вокруг таймаута клиента, чтобы прошивка могла его сократить. С
исходным таймаутом лампа подвисает при открытии страницы настроек.

**GyverDB.** `GyverDBFile.h` записывает настройки во временный файл и подменяет им основной.
Без правки файл обрезался до нуля перед записью, и перезагрузка во время записи стирала все
настройки.

**arduinoWebSockets.** В `WebSockets.h` ожидания TCP разнесены по стадиям и укорочены:
рукопожатие 700 мс, дочитывание кадра 1100 мс, отправка 1500 мс. Без правки каждое ожидание
брало общий таймаут 5000 мс и на это время останавливало лампу. Значения разные, чтобы по
длительности провала в Журнале было видно стадию. Отправка, упёршаяся в таймаут, рвёт
соединение: вкладка, приостановленная браузером на телефоне, иначе тормозила бы каждую
следующую рассылку. Settings вдобавок пингует клиентов (`core/SyncWS.h`) и отключает не
ответивших дважды.
