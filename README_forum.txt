[B]GyverLamp 3.0 — переработка прошивки gunner47 v2.87in1[/B]

Переработана система управления прошивки gunner47_v2.87in1 для WiFi-лампы. Все [B]87 исходных эффектов сохранены без изменений[/B] (плюс два новых: Змейка и Земля), аппаратная совместимость полная — та же плата (Wemos D1 mini), та же распиновка (лента D4, кнопка D2).

[B]Что сделано[/B]
[LIST]
[*][B]Убрана поддержка Android/iOS приложений и Blynk[/B] — приложения устарели и на последних версиях Android уже не устанавливаются. Вместо этого всё управление перенесено на библиотеку [URL='https://github.com/GyverLibs/Settings']GyverLibs/Settings[/URL]: страница настроек открывается в браузере по IP лампы (или на http://192.168.4.1, когда лампа работает точкой доступа).
[*][B]Нативное управление с Яндекс Алисы[/B] — через MQTT (например, брокер wqtt.ru): формат топиков совместим со старой прошивкой, плюс отдельные топики power/brightness/speed для простой привязки (таблица ниже).
[*]WiFi через [URL='https://github.com/GyverLibs/WiFiConnector']WiFiConnector[/URL]: при недоступном роутере лампа не перезагружается по кругу, а остаётся точкой доступа с работающей страницей настроек.
[*]Все настройки хранятся в файле на LittleFS (GyverDB) вместо сырого EEPROM. Параметры WiFi, MQTT и NTP меняются со страницы, без перепрошивки.
[*][B]Вывод на ленту через аппаратный UART1[/B] (NeoPixelBus, тот же пин D4/GPIO2 — без перепайки) вместо программного битбангинга FastLED. Полностью убрано мигание первого пикселя от WiFi-прерываний (на ESP8266 WiFi использует немаскируемые прерывания, поэтому программный вывод портит кадры, что ни настраивай). FastLED остался для всей математики эффектов.
[*]Кнопка работает как раньше: 1–7 кликов и удержания без изменений.
[*]Два новых эффекта под форм-фактор лампы-цилиндра: [B]Змейка[/B] (классическая игра с Nokia: змейка сама охотится за едой и растёт, по горизонтали свободно уползает за «край» цилиндра и путь считает с учётом заворота; Масштаб — цвет) и [B]Земля[/B] (вращающаяся карта планеты; при синхронизированном времени ночная сторона затемняется по реальному положению Солнца).
[*]Опциональная [B]автояркость[/B] по датчику освещённости на A0: в темноте лампа плавно тускнеет до настраиваемого минимума. Включается на странице настроек (по умолчанию выключена — прошивка одинаково работает на лампе без датчика), там же живая диагностика значений датчика, чувствительность и инверсия.
[*]Бонус: [B]Wake-on-LAN[/B] — лампа умеет будить компьютер в локальной сети магическим пакетом (кнопкой на странице настроек или по MQTT) — отдельная железка для WoL больше не нужна, лампа и так всегда в сети.
[/LIST]

[B]Со страницы настроек доступно[/B]
[LIST]
[*]питание, выбор эффекта (номера в списке совпадают с номерами эффектов в MQTT-командах), яркость/скорость/масштаб — при смене эффекта ползунки подтягивают его настройки;
[*]режим Цикл: интервал, случайный разброс, случайные настройки эффектов, выбор эффектов чек-листом;
[*]будильники-«рассветы» по дням недели, время начала рассвета;
[*]таймер выключения, бегущая строка, блокировка кнопки;
[*]настройки WiFi (SSID/пароль, режим точка доступа/клиент), MQTT (брокер, порт, логин/пароль), NTP-сервер;
[*]ручная установка времени, журнал событий (WiFi/MQTT/NTP/причина перезагрузки), OTA-обновление прошивки прямо со страницы;
[*]открытая страница обновляется сама, если лампой управляют другим способом (MQTT, кнопка, режим Цикл).
[/LIST]

При первой прошивке поверх старой версии лампа забудет настройки (формат хранения другой): нужно один раз подключиться к точке доступа "LedLamp 1" (пароль 31415926) и настроить WiFi на http://192.168.4.1.

[B]Что требуется для сборки[/B]

Ядро esp8266 [B]3.1.2 или новее[/B] (Boards Manager URL: https://arduino.esp8266.com/stable/package_esp8266com_index.json), плата [B]LOLIN(WEMOS) D1 R2 & mini[/B].

Настройки IDE:
[LIST]
[*]Flash Size: [B]4MB (FS:2MB OTA:~1019KB)[/B] — файловая система обязательна;
[*]Erase Flash: [B]All Flash Contents[/B] для первой прошивки, дальше — Only Sketch (иначе настройки будут стираться при каждой прошивке);
[*]остальное — по умолчанию (CPU 80 MHz достаточно).
[/LIST]

[B]MQTT[/B]

Идентификатор лампы: LedLamp_XXXXXXXX, где XXXXXXXX — chip id (топики целиком показываются на странице настроек в разделе MQTT). Брокер, порт, логин и пароль задаются там же; пока адрес брокера пустой, MQTT-клиент не запускается.

Команды (входящие):
[TABLE]
[TR]
[TD][B]Топик[/B][/TD][TD][B]Payload[/B][/TD]
[/TR]
[TR]
[TD]LedLamp/<id>/cmnd/power[/TD][TD]true/1/on — включить, иначе выключить[/TD]
[/TR]
[TR]
[TD]LedLamp/<id>/cmnd/effect[/TD][TD]номер эффекта 0..88[/TD]
[/TR]
[TR]
[TD]LedLamp/<id>/cmnd/brightness[/TD][TD]1-100 (масштабируется в 1-255); больше 100 — как есть[/TD]
[/TR]
[TR]
[TD]LedLamp/<id>/cmnd/speed[/TD][TD]1-100 (масштабируется в 1-255); больше 100 — как есть[/TD]
[/TR]
[TR]
[TD]LedLamp/<id>/cmnd/scale[/TD][TD]масштаб, как есть[/TD]
[/TR]
[TR]
[TD]LedLamp/<id>/cmnd/button[/TD][TD]true/1/on — разблокировать кнопку, иначе заблокировать[/TD]
[/TR]
[TR]
[TD]LedLamp/<id>/cmnd/wol[/TD][TD]Wake-on-LAN: MAC компьютера (AA:BB:CC:DD:EE:FF), либо пусто/true/1/on — MAC из настроек (false/0/off игнорируется). Можно включить слежение за дополнительным произвольным топиком (настраивается на странице)[/TD]
[/TR]
[TR]
[TD]LedLamp/<id>/cmnd[/TD][TD]текстовые команды, формат совместим с прошивками 2.x: P_ON, P_OFF, EFFn, BRIn, SPDn, SCAn, BTN ON/OFF, TEXT текст, ALM_SETd ON/OFF/минуты, DAWNn, TMR_SET 1 о сек, FAV_SET ..., WOL [MAC][/TD]
[/TR]
[/TABLE]

Команда смены эффекта (EFFn или топик effect) на выключенной лампе также включает её.

Состояние (исходящее, retained, публикуется после каждого изменения) — топик LedLamp/<id>/state:
[CODE]
{"effect":5,"brightness":42,"speed":60,"scale":40,"power":true,"espMode":1,
 "useNtp":true,"timerRunning":false,"buttonEnabled":true,"time":"21:25:50"}
[/CODE]

Яркость и скорость в состоянии отдаются в диапазоне 1-100 — удобно напрямую привязывать к «яркости» умного устройства в Алисе.
